Get an author by ID

Get an author by ID. The author's books and series can be included in the response.

Authorizations:
BearerAuth
path Parameters
id
required
string <uuid> (authorId)
Example: e4bb1afb-4a4f-4dd6-8be0-e615d233185b

Author ID

query Parameters
include
string
Example: include=items,series

A comma separated list of what to include with the author. The options are items and series. series will only have an effect if items is included. For example, the value items,series will include both library items and series.

Responses

Development server

http://localhost:3000/api/authors/{id}

Update an author by ID

Update an author by ID. The author's name and description can be updated. This endpoint will merge two authors if the new author name matches another author name in the database.

Authorizations:
BearerAuth
path Parameters
id
required
string <uuid> (authorId)
Example: e4bb1afb-4a4f-4dd6-8be0-e615d233185b

Author ID

Request Body schema: application/json

The author object to update.

name
string (authorName)

The name of the author.

description
string or null (authorDescription)

The new description of the author.

imagePath
string or null (authorImagePath)

The absolute path for the author image. This will be in the metadata/ directory. Will be null if there is no image.

asin
string or null (authorAsin)

The Audible identifier (ASIN) of the author. Will be null if unknown. Not the Amazon identifier.

http://localhost:3000/api/authors/{id}

Get an author image by author ID

Get an author image by author ID. The image will be returned in the requested format and size.

path Parameters
id
required
string <uuid> (authorId)
Example: e4bb1afb-4a4f-4dd6-8be0-e615d233185b

Author ID

query Parameters
token
string

API token

ts
integer

Updated at value

Request Body schema: application/json
optional

The author image to get.

width
integer (imageWidth)
Default: 400

The requested width of image in pixels.

height
integer or null (imageHeight)
Default: null

The requested height of image in pixels. If null, the height is scaled to maintain aspect ratio based on the requested width.

format
string (imageFormat)
Default: "jpeg"

The requested output format.

raw
boolean (imageRaw)
Default: false

Return the raw image without scaling if true.

Match the author against Audible using quick match

Match the author against Audible using quick match. Quick match updates the author's description and image (if no image already existed) with information from audible. Either asin or q must be provided, with asin taking priority if both are provided.

Authorizations:
BearerAuth
path Parameters
id
required
string <uuid> (authorId)
Example: e4bb1afb-4a4f-4dd6-8be0-e615d233185b

Author ID

Request Body schema: application/json
required

The author object to match against an online provider.

q
string (authorSearchName)

The name of the author to use for searching.

asin
string or null (authorAsin)

The Audible identifier (ASIN) of the author. Will be null if unknown. Not the Amazon identifier.

region
string (region)
Default: "us"

The region used to search.
